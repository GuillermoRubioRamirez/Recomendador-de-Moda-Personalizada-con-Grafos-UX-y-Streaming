## Sistema inteligente de recomendación de outfits
Proyecto desarrollado en colaboración con Lookiero, centrado en mejorar la experiencia de usuario y la eficiencia del sistema de recomendación.

Se implementó un sistema de generación de looks mediante teoría de grafos, clasificando las prendas según jerarquías estilísticas y conectando nodos en función de reglas definidas. Sobre esta base, se desarrolló una red neuronal de grafos (GNN) capaz de predecir combinaciones óptimas de prendas, incorporando datos estructurados y relaciones complejas entre ellas.

En paralelo, se realizó un análisis UX que permitió detectar fricciones en la navegación web, proponiendo mejoras apoyadas en datos de Google Tag Manager. Finalmente, se diseñó un flujo de streaming de datos en tiempo real con Apache Kafka y Spark para generar recomendaciones dinámicas en función de nuevos productos y las preferencias cambiantes de las clientas, integrando así inteligencia artificial, datos y diseño centrado en el usuario.
